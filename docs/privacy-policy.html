SmartFav

Privacy Policy / 隐私政策

Effective date / 生效日期：July 24, 2026 / 2026 年 7 月 24 日

English 简体中文

English

SmartFav is a local-first favorites organizer for Microsoft Edge. Local classification is the default; AI and browser-favorites features are optional and controlled by the user.

1. Information SmartFav accesses

  • The active page URL, title, favicon URL, meta description or a short text excerpt, and page keywords.
  • Favorites saved in SmartFav, including URL, title, description excerpt, category, tags, classification summary, and creation time.
  • Microsoft Edge favorites when browser-favorites synchronization, organization, or automatic capture is explicitly enabled.
  • Extension settings, including language, theme, popup size, category rules, an optional custom background image, AI provider/model choices, and an optional API key.
  • Recently deleted SmartFav favorites, retained locally for up to seven days so that they can be restored.

2. Local processing and storage

By default, classification is performed locally in Microsoft Edge. Favorites, settings, recently deleted items, custom background images, and any API key are stored in the extension's local browser storage. SmartFav does not require an account and does not operate a publisher-controlled server, analytics service, advertising system, or cross-site tracking service.

3. Optional AI services

AI enhancement is off by default. If enabled, SmartFav sends a classification request directly to the provider selected by the user. A request may include the page title and URL, description or short text excerpt, page keywords, category names and rules, local scores and field weights, model name, and classification prompt.

For a cloud provider, the user's API key is sent only to that provider for authentication. Supported services include OpenRouter, MiniMax, DeepSeek, OpenAI, and a local Ollama service. Cloud-provider processing is governed by that provider's own terms and privacy policy. The publisher does not receive AI prompts, page information, API keys, or responses.

4. Microsoft Edge favorites access

The `bookmarks` permission supports three independent options that are off by default: synchronization with managed `SmartFav / Category` folders, user-authorized organization of existing URL favorites, and automatic capture of new favorites. SmartFav does not upload Edge favorites to the publisher. Browser favorites are moved, created, or removed only according to the controls selected by the user.

5. Retention and deletion

  • Local extension data remains until it is deleted, extension data is cleared, or the extension is uninstalled.
  • Recently deleted items are retained for up to seven days unless restored or permanently deleted sooner.
  • Browser favorites created or moved at the user's request remain in Edge until the user removes or reorganizes them.
  • Information sent to an AI provider is retained according to that provider's policy.

6. Sharing, sale, and tracking

SmartFav does not sell personal information and does not share information for advertising, analytics, credit scoring, or cross-site tracking. Information is disclosed only to an AI provider selected and enabled by the user, as necessary to perform the requested classification.

7. User controls

Users can keep AI disabled, remove an API key, change providers, independently disable browser-favorites features, edit category rules, delete or restore SmartFav items, permanently delete recently deleted items, clear extension data, or uninstall the extension.

8. Security

Cloud AI requests use HTTPS. API keys are stored locally and are sent only to the selected provider. A local Ollama endpoint may use HTTP on `localhost`. Users should protect their browser profile and API credentials.

9. Children

SmartFav is a general productivity tool and is not directed to children. The publisher does not knowingly collect children's personal information.

10. Changes and contact

This policy will be updated if SmartFav's data practices materially change. For privacy questions or requests, open an issue at github.com/003jia/SmartFav/issues.

简体中文

SmartFav 是一款以本地处理为优先的 Microsoft Edge 收藏整理扩展。本地分类默认开启；AI 和浏览器收藏夹功能均为可选，并由用户控制。

1. SmartFav 访问的信息

  • 当前网页的网址、标题、网站图标地址、Meta 描述或一小段网页文本，以及网页关键词。
  • 保存在 SmartFav 中的收藏，包括网址、标题、描述摘要、分类、标签、分类说明和创建时间。
  • 明确开启浏览器收藏夹同步、整理或自动获取功能后访问的 Microsoft Edge 收藏夹。
  • 扩展设置，包括语言、主题、弹窗尺寸、分类规则、可选的自定义背景图、AI 服务商与模型，以及可选的 API Key。
  • 最近删除的 SmartFav 收藏；这些记录仅在本地保留最多 7 天，以便恢复。

2. 本地处理与存储

默认情况下，SmartFav 在 Microsoft Edge 本地完成分类。收藏、设置、最近删除内容、自定义背景图和 API Key 均保存在扩展的浏览器本地存储中。SmartFav 不要求注册账号，也不运营发布方控制的服务器、分析服务、广告系统或跨站跟踪服务。

3. 可选 AI 服务

AI 增强默认关闭。开启后，SmartFav 会直接向用户选择的服务商发送分类请求。请求可能包含网页标题和网址、描述或一小段网页文本、网页关键词、分类名称和规则、本地得分和字段权重、模型名称以及分类提示词。

使用云端服务商时，API Key 只会发送给该服务商用于身份验证。支持的服务包括 OpenRouter、MiniMax、DeepSeek、OpenAI 和本机 Ollama。云端服务商如何处理信息，受其自身条款和隐私政策约束。发布方不会收到 AI 提示词、网页信息、API Key 或返回结果。

4. Microsoft Edge 收藏夹权限

`bookmarks` 权限支持三个默认关闭的独立选项：同步受管理的 `SmartFav / 分类` 文件夹、经用户授权整理现有网址收藏，以及自动获取新收藏。SmartFav 不会把 Edge 收藏夹上传给发布方。只有根据用户选择的开关，才会移动、新建或删除浏览器收藏。

5. 保留与删除

  • 本地扩展数据会保留到用户删除、清除扩展数据或卸载扩展。
  • 最近删除内容保留最多 7 天，用户可以提前恢复或永久删除。
  • 按用户要求创建或移动的浏览器收藏会保留在 Edge 中，直到用户自行删除或重新整理。
  • 发送给 AI 服务商的信息按照该服务商的政策保留。

6. 共享、出售与跟踪

SmartFav 不出售个人信息，也不会为了广告、分析、信用评估或跨站跟踪而共享信息。只有用户选择并开启 AI 服务后，才会为完成用户请求的分类而向该服务商披露必要信息。

7. 用户控制

用户可以保持关闭 AI、删除 API Key、更换服务商、分别关闭浏览器收藏夹功能、编辑分类规则、删除或恢复 SmartFav 收藏、永久删除最近删除内容、清除扩展数据或卸载扩展。

8. 安全

云端 AI 请求使用 HTTPS。API Key 保存在本地，并且只会发送给用户选择的服务商。本机 Ollama 地址可能通过 `localhost` 使用 HTTP。用户应妥善保护浏览器配置文件和 API 凭据。

9. 儿童

SmartFav 是通用效率工具，并非面向儿童。发布方不会主动收集儿童个人信息。

10. 政策更新与联系

如果 SmartFav 的数据处理方式发生重大变化，本政策会同步更新。如有隐私问题或请求，请访问 github.com/003jia/SmartFav/issues 提交 Issue。
