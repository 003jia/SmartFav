SmartFav

Privacy Policy / 隐私政策

Effective date / 生效日期：July 29, 2026 / 2026 年 7 月 29 日

English 简体中文

English

SmartFav is a local-first favorites organizer for Microsoft Edge. Local classification is the default; AI and browser-favorites features are optional and controlled by the user.

1. Information SmartFav accesses

  • The active page URL, title, favicon URL, meta description or a short text excerpt, and page keywords.
  • Favorites saved in SmartFav, including URL, title, description excerpt, category, tags, classification summary, and creation time.
  • Microsoft Edge favorites when browser-favorites synchronization, organization, or automatic capture is explicitly enabled.
  • Pre-organization layout backups for bookmarks still outside SmartFav, including bookmark IDs, titles, URLs, original folder paths, and ordering.
  • Extension settings, including language, theme, popup size, category rules, an optional custom background image, AI provider/model choices, an optional custom API endpoint, and an optional API key.
  • Recently deleted SmartFav favorites, retained locally for up to seven days so that they can be restored.

2. Local processing and storage

By default, classification is performed locally in Microsoft Edge. Favorites, settings, recently deleted items, pre-organization layout backups, custom background images, and any API key are stored in the extension's local browser storage. Layout backups can be exported by the user as a JSON file and imported later. SmartFav does not require an account and does not operate a publisher-controlled server, analytics service, advertising system, or cross-site tracking service.

3. Optional AI services

AI enhancement is off by default. If enabled, SmartFav sends a classification request directly to the provider selected by the user. A request may include the page title and URL, description or short text excerpt, page keywords, category names and rules, local scores and field weights, model name, and classification prompt.

When the user clicks “AI keyword suggestions,” SmartFav sends folder names, existing non-domain keywords, and the title, domain, and query-free URL path of up to 12 representative favorites from each non-empty folder. Query parameters and URL fragments are excluded. Suggestions are filled into local editable fields and are not saved until the user selects “Save and reclassify.”

For a cloud provider, the user's API key is sent only to that provider for authentication. SmartFav supports OpenRouter, MiniMax, DeepSeek, OpenAI, a local Ollama service, and user-configured endpoints using the OpenAI Chat Completions or Anthropic Messages format. A custom endpoint operator selected by the user receives the request and API key under that operator's own terms and privacy policy. The publisher does not receive AI prompts, page information, API keys, or responses.

Custom remote endpoints must use HTTPS. When saving or testing a compatible API configuration, SmartFav asks the browser for access only to the configured API host. HTTP custom endpoints are accepted only on localhost or 127.0.0.1.

4. Microsoft Edge favorites access

The bookmarks permission supports three independent options that are off by default: synchronization with managed SmartFav / Category folders, user-authorized organization of existing URL favorites, and automatic capture of new favorites. SmartFav category moves can move managed browser copies, and moving a browser favorite between managed SmartFav categories updates the local category. When synchronization or automatic capture is enabled, deleting the last browser favorite with a matching URL moves the SmartFav item to Recently deleted; deleting one duplicate copy does not remove it. New stars are classified locally and may trigger a local system notification naming the destination category. The notifications permission only displays this result on the user's device. SmartFav does not upload Edge favorites or notification content to the publisher.

Before organizing existing favorites or automatically moving a new favorite, SmartFav saves a local layout backup for bookmarks that are still outside SmartFav. If the backup cannot be saved, favorites are not moved. Bookmarks already inside SmartFav can be read, but the browser does not expose their earlier locations. Restoration moves only existing bookmarks whose browser IDs match the record, recreates missing folder paths when needed, and attempts to restore the recorded order. It does not delete bookmarks added later or recreate bookmarks the user deleted.

5. Retention and deletion

  • Local extension data remains until it is deleted, extension data is cleared, or the extension is uninstalled.
  • Local layout backups are deleted when extension data is cleared or the extension is uninstalled. Browsers do not allow the extension to run an automatic restore after uninstallation. An exported JSON file remains where the user saved it until the user deletes it.
  • Recently deleted items are retained for up to seven days unless restored or permanently deleted sooner.
  • Browser favorites created or moved at the user's request remain in Edge until the user removes or reorganizes them.
  • Information sent to an AI provider is retained according to that provider's policy.

6. Sharing, sale, and tracking

SmartFav does not sell personal information and does not share information for advertising, analytics, credit scoring, or cross-site tracking. Information is disclosed only to an AI provider selected and enabled by the user, as necessary to perform the requested classification or keyword suggestion.

7. User controls

Users can keep AI disabled, remove an API key, change providers, review, edit, or discard AI keyword suggestions before saving, independently disable browser-favorites features, edit category rules, scan or update a pre-organization layout backup, preview or run a restore, export or import layout-backup JSON, delete or restore SmartFav items, permanently delete recently deleted items, clear extension data, or uninstall the extension.

8. Security

Cloud AI requests use HTTPS. API keys and custom endpoint settings are stored locally and are sent only to the selected provider or user-configured endpoint. A local Ollama or compatible endpoint may use HTTP only on localhost or 127.0.0.1. Users should protect their browser profile and API credentials.

9. Children

SmartFav is a general productivity tool and is not directed to children. The publisher does not knowingly collect children's personal information.

10. Changes and contact

This policy will be updated if SmartFav's data practices materially change. For privacy questions or requests, open an issue at github.com/003jia/SmartFav/issues.

简体中文

SmartFav 是一款以本地处理为优先的 Microsoft Edge 收藏整理扩展。本地分类默认开启；AI 和浏览器收藏夹功能均为可选，并由用户控制。

1. SmartFav 访问的信息

  • 当前网页的网址、标题、网站图标地址、Meta 描述或一小段网页文本，以及网页关键词。
  • 保存在 SmartFav 中的收藏，包括网址、标题、描述摘要、分类、标签、分类说明和创建时间。
  • 明确开启浏览器收藏夹同步、整理或自动获取功能后访问的 Microsoft Edge 收藏夹。
  • 为仍在 SmartFav 外的书签创建的整理前布局备份，包括书签 ID、标题、网址、原文件夹路径和顺序。
  • 扩展设置，包括语言、主题、弹窗尺寸、分类规则、可选的自定义背景图、AI 服务商与模型、可选的自定义 API 地址，以及可选的 API Key。
  • 最近删除的 SmartFav 收藏；这些记录仅在本地保留最多 7 天，以便恢复。

2. 本地处理与存储

默认情况下，SmartFav 在 Microsoft Edge 本地完成分类。收藏、设置、最近删除内容、整理前布局备份、自定义背景图和 API Key 均保存在扩展的浏览器本地存储中。用户可以把布局备份导出为 JSON 文件并在之后重新导入。SmartFav 不要求注册账号，也不运营发布方控制的服务器、分析服务、广告系统或跨站跟踪服务。

3. 可选 AI 服务

AI 增强默认关闭。开启后，SmartFav 会直接向用户选择的服务商发送分类请求。请求可能包含网页标题和网址、描述或一小段网页文本、网页关键词、分类名称和规则、本地得分和字段权重、模型名称以及分类提示词。

用户点击“AI 分析并填入”时，SmartFav 会发送文件夹名称、已有的非域名关键词，以及每个非空文件夹最多 12 条代表性收藏的标题、域名和不含查询参数的网址路径。请求不包含网址查询参数或片段；建议会先填入本地可编辑字段，只有点击“保存并重新分类”后才会保存。

使用云端服务商时，API Key 只会发送给该服务商用于身份验证。SmartFav 支持 OpenRouter、MiniMax、DeepSeek、OpenAI、本机 Ollama，以及用户配置的 OpenAI Chat Completions 或 Anthropic Messages 格式接口。用户选择的自定义接口运营方会按照其自身条款和隐私政策接收请求内容与 API Key。发布方不会收到 AI 提示词、网页信息、API Key 或返回结果。

自定义远程接口必须使用 HTTPS。保存或测试兼容 API 配置时，SmartFav 只向浏览器请求所填写 API 主机的访问权限。HTTP 自定义接口仅允许使用 localhost 或 127.0.0.1。

4. Microsoft Edge 收藏夹权限

bookmarks 权限支持三个默认关闭的独立选项：同步受管理的 SmartFav / 分类 文件夹、经用户授权整理现有网址收藏，以及自动获取新收藏。SmartFav 内跨分类移动可以同步移动受管理的浏览器副本；用户在浏览器受管理分类之间移动书签时，也会更新 SmartFav 本地分类。开启同步或自动获取后，删除最后一条同网址浏览器书签会把 SmartFav 收藏移入“最近删除”；仅删除重复副本不会误删。新建星标会在本地分类，并可通过本机系统通知显示目标分类；notifications 权限仅用于显示这一结果。SmartFav 不会把 Edge 收藏夹或通知内容上传给发布方。

整理现有收藏或自动移动新收藏前，SmartFav 会先为仍在 SmartFav 外的书签保存本地布局备份；备份无法保存时不会移动收藏。已经位于 SmartFav 分类内的书签仍可读取，但浏览器不提供其更早位置。还原只移动仍然存在且浏览器书签 ID 与记录匹配的书签，按需重建缺失文件夹，并尝试恢复记录顺序；不会删除之后新增的书签，也不会重新创建用户已删除的书签。

5. 保留与删除

  • 本地扩展数据会保留到用户删除、清除扩展数据或卸载扩展。
  • 清除扩展数据或卸载扩展会删除本地布局备份；浏览器不允许扩展在卸载后自动执行还原。用户导出的 JSON 文件会保留在保存位置，直到用户自行删除。
  • 最近删除内容保留最多 7 天，用户可以提前恢复或永久删除。
  • 按用户要求创建或移动的浏览器收藏会保留在 Edge 中，直到用户自行删除或重新整理。
  • 发送给 AI 服务商的信息按照该服务商的政策保留。

6. 共享、出售与跟踪

SmartFav 不出售个人信息，也不会为了广告、分析、信用评估或跨站跟踪而共享信息。只有用户选择并开启 AI 服务后，才会为完成用户请求的分类或关键词建议而向该服务商披露必要信息。

7. 用户控制

用户可以保持关闭 AI、删除 API Key、更换服务商、在保存前查看、编辑或放弃 AI 关键词建议、分别关闭浏览器收藏夹功能、编辑分类规则、扫描或更新整理前布局备份、预览或执行还原、导入或导出布局备份 JSON、删除或恢复 SmartFav 收藏、永久删除最近删除内容、清除扩展数据或卸载扩展。

8. 安全

云端 AI 请求使用 HTTPS。API Key 和自定义接口设置保存在本地，并且只会发送给用户选择的服务商或自定义接口。本机 Ollama 或兼容接口仅可通过 localhost 或 127.0.0.1 使用 HTTP。用户应妥善保护浏览器配置文件和 API 凭据。

9. 儿童

SmartFav 是通用效率工具，并非面向儿童。发布方不会主动收集儿童个人信息。

10. 政策更新与联系

如果 SmartFav 的数据处理方式发生重大变化，本政策会同步更新。如有隐私问题或请求，请访问 github.com/003jia/SmartFav/issues 提交 Issue。
