# SmartFav 1.14.0

SmartFav 是一款本地优先、AI 可选增强的 Chrome / Edge 智能书签整理插件。本版本先交付一版可控的“从用户修正中学习”：书签被手动移到新分类后，由用户决定是否记住该网站的域名归属。

## 本次更新

- 本地分类结果新增“把握高 / 中 / 低”，并继续显示实际匹配依据。
- 在 SmartFav 分类内跨分类移动书签后，显示“记住这次分类？”确认卡片。
- 点击“这次不用”不会写入任何规则；点击“记住”才会保存域名规则。
- 学习规则使用公开可读的 `domain:example.com` 格式，显示在“分类文件夹”的关键词输入框中，可随时编辑或删除。
- 域名规则同时适用于加权关键词和本地向量两种分类模式。
- 同一域名已有旧分类规则时，界面会先说明冲突；确认后把规则移动到新分类，避免一条域名同时指向多个分类。
- 新规则用于之后的插件收藏、浏览器星标自动获取和浏览器收藏夹整理。
- 第一版不会自动重分已有收藏，也不会在用户未确认时静默学习。

## 下载与安装

下载 `SmartFav-Edge-1.14.0.zip`，解压后：

1. 打开 `edge://extensions/` 或 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后包含 `manifest.json` 的目录。

此 ZIP 同时适用于 Edge 和 Chrome 的开发者模式安装，也可用于扩展商店提交。它不是可双击安装的桌面应用安装包。
