# SmartFav 1.14.1

SmartFav 1.14.1 将确认式分类学习扩展到当前网页收藏流程。用户修改本地或 AI 推荐分类后，可以在保存网页的同时记住该网站的域名归属，并在保存后立即撤销。

## 本次更新

- 当前网页手动修改推荐分类后，显示“同时记住这个网站的分类”。
- 普通分类默认勾选学习，点击收藏时同步写入 `domain:example.com`。
- “其他”通常是临时归类，因此默认不勾选；用户仍可主动开启。
- 同一域名已有旧规则时，界面会说明规则将从哪个分类移动到新分类。
- 收藏与学习规则使用同一次本地存储写入，避免发生只保存收藏或只保存规则的中间状态。
- 保存后显示“撤销记住”；撤销恢复原关键词规则，但收藏仍保留在用户手动选择的分类。
- 学习规则继续用于后续插件收藏、浏览器星标自动获取和浏览器收藏夹整理。
- 不会自动重新分类已有收藏。

## 下载与安装

下载 `SmartFav-Edge-1.14.1.zip`，解压后：

1. 打开 `edge://extensions/` 或 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后包含 `manifest.json` 的目录。

更新已有开发者模式安装时，建议覆盖原扩展目录并点击“重新加载”，不要先删除旧扩展，以免浏览器分配新的扩展身份。

从本版本开始只提供 ZIP，不再单独生成 SHA-256 文件。发布前仍会在本地执行 ZIP 完整性检查。

## 验证范围

- 手动改分类后普通分类默认学习。
- “其他”默认不学习，但允许用户主动勾选。
- 改回推荐分类后隐藏学习选项。
- 中文与英文文案。
- 明亮与暗色界面。
- 保存后规则写入、冲突迁移和一键撤销。
- 撤销后规则恢复，已收藏网页仍保留在手动选择的分类。
- JavaScript 语法、完整自动化回归和 ZIP 完整性。
