# SmartFav 1.14.5

SmartFav 1.14.5 集中修复自定义背景图与毛玻璃主题的一致性。基础收藏、本地分类、AI 可选增强、浏览器收藏同步、最近删除和布局备份行为保持不变。

## 更新内容

- 自定义背景图改为大尺寸取景预览，可直接拖动图片选择最终显示区域。
- 支持方向键 2% 微调、`Shift + 方向键` 10% 调整和“一键居中”。
- 新增横向与纵向位置设置，选择后自动保存并随插件重启恢复。
- 旧版本背景图自动按 50% / 50% 居中迁移，不需要重新上传。
- 毛玻璃主题统一外壳、内容面板、下拉框、次级按钮、标签、分类卡片和设置控件的半透明模糊材质。
- 降低明亮与暗色背景遮罩，让自定义图片保持可见，同时保留文字与控件边界。
- 中文与 English 均补充拖动、键盘微调和自动保存说明。

## 验证

- 全部扩展 JavaScript 语法检查通过。
- `tests/verify-extension.js` 通过，包括版本、迁移字段、拖动事件、键盘事件、样式变量和中英文文案检查。
- 浏览器预览已验证上传、位置微调、一键居中、明亮、暗色、中文、English 和 360 × 560 紧凑尺寸。
- 发布 ZIP 通过源码文件清单与逐文件字节一致性检查。

## 安装

下载 `dist/SmartFav-Edge-1.14.5.zip`，解压后在 `edge://extensions/` 或 `chrome://extensions/` 中开启开发者模式并加载解压目录。

提交商店时可直接上传该 ZIP；`manifest.json` 位于压缩包根目录。
