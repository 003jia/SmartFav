# SmartFav 1.15.0

SmartFav 1.15.0 将平铺分类升级为真正的多级收藏夹树，同时保持“本地分类始终可用，AI 只是可选增强”的产品边界。

## 更新内容

- 新增稳定 `folderId` / `favoriteId` 与 `folderSchemaVersion: 2`，支持任意层级、同父级唯一命名和不同父级同名。
- 旧 `categories`、关键词、收藏归属和排序自动幂等迁移。
- 主页和分类管理页支持面包屑、逐级进入、子目录新建、重命名、同级排序和跨层移动。
- 非空文件夹删除前必须选择迁移目标；子树保持结构，同名冲突不自动合并。
- 浏览器 `SmartFav` 子树递归双向同步，并在 service worker 启动时对账扩展停止期间的变更。
- 整个浏览器 `SmartFav` 根目录被删除时，本地树不会丢失；重新启用写入可完整重建。
- 本地分类对全部文件夹路径评分，父级关键词每向上一层按 `0.35` 衰减。
- AI 单页分类返回稳定文件夹 ID、置信度、理由和可选新建建议；低于 `0.75` 时保留到根级“其他”。
- “AI 整理建议”只发送每个文件夹最多 12 条代表性收藏的标题、域名和不含查询参数的路径。
- AI 只能建议移动收藏、创建子文件夹和补充关键词；不允许删除、合并或重命名已有文件夹。
- 建议先进入可勾选预览，未应用前不修改本地或浏览器数据；批量应用前自动建立布局还原点。

## 验证

- 四层目录创建、重载、重命名、移动与排序。
- 不同父级同名目录与同级重名冲突。
- 浏览器端跨层移动和启动对账。
- 同网址覆盖模式和多副本新增模式。
- AI 未知 ID、不允许操作和恶意文件夹名称拦截。
- AI 预览不落盘与批量中断后还原入口。
- 全部 JavaScript 语法检查、`tests/verify-extension.js`、ZIP 结构和发布包源码一致性检查。

## 安装

下载 `SmartFav-Edge-1.15.0.zip`，解压后在 `edge://extensions/` 或 `chrome://extensions/` 中开启开发者模式并加载解压目录。提交扩展商店时可直接上传 ZIP。
