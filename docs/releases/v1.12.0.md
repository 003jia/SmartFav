# SmartFav 1.12.0

SmartFav 是一款本地优先、AI 可选增强的 Chrome / Edge 智能书签整理插件。本版本补齐拖动排序与浏览器收藏夹之间的同步闭环，并更新 GitHub 展示与可下载软件包。

## 本次更新

- 分类文件夹与分类内书签支持鼠标拖动和 `Alt + 方向键` 排序。
- 开启“同步浏览器收藏夹”后，SmartFav 中的手动顺序会写回浏览器 `SmartFav / 分类`。
- 同网址的多个受管副本会全部保留，并维持相对顺序。
- 未匹配书签、未知文件夹及 SmartFav 目录外内容不会被移动或删除。
- 同步失败或浏览器缺少对应项目时，仍保留本地排序并显示明确提示。
- 统一设置页复选框尺寸，优化 GitHub 项目介绍和功能展示图。

## 下载与安装

下载 `SmartFav-Edge-1.12.0.zip`，解压后：

1. 打开 `edge://extensions/` 或 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后包含 `manifest.json` 的目录。

此 ZIP 同时适用于 Edge 和 Chrome 的开发者模式安装，也可用于扩展商店提交。它不是可双击安装的桌面应用安装包。

可使用随附的 `SmartFav-Edge-1.12.0.sha256` 校验下载文件完整性。
