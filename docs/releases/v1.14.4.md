# SmartFav 1.14.4

SmartFav 1.14.4 是后台分层与可验证性版本。它不新增用户数据字段，也不改变 1.14.3 的收藏、分类、同步、回收站和备份行为，现有数据可以直接升级。

## 本次更新

- 新增 `state-store.js`：集中状态默认值、读取、合并写入与 storage 错误处理。
- 新增 `bookmark-guard.js`：集中内部书签操作标记、浏览器事件队列和布局事务锁。
- 新增 `favorites-service.js`：承接收藏、浏览器同步、回收站、整理、排序和备份业务。
- `background.js` 从 1396 行缩减为 248 行，仅保留生命周期、书签事件监听和 21 条消息路由。
- 所有收藏相关写入继续使用同一个 `bookmarkGuard` 实例，不产生第二把布局锁。
- 自动化测试改为执行真实 `importScripts` 链，能够发现文件遗漏、加载顺序和全局导出错误。
- 增加 guard 直接测试：独立实例隔离、队列严格串行、失败后继续执行、worker 重启后的 session 标记恢复。

## 兼容性

- Manifest V3，适用于 Chromium 内核的 Edge 与 Chrome。
- 存储键、消息类型、消息响应形状、默认分类词表均保持不变。
- 无 API Key 时仍可完整使用本地分类；AI 继续是可选增强。
- 1.14.3 已有收藏、分类、关键词、顺序、回收站和书签还原点无需迁移。

## 安装包

下载 `dist/SmartFav-Edge-1.14.4.zip`，解压后在 `edge://extensions/` 或 `chrome://extensions/` 中开启开发者模式并加载解压目录。

发布包必须通过：

```bash
unzip -t dist/SmartFav-Edge-1.14.4.zip
node tests/verify-release-package.js dist/SmartFav-Edge-1.14.4.zip
```
