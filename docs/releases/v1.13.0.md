# SmartFav 1.13.0

SmartFav 是一款本地优先、AI 可选增强的 Chrome / Edge 智能书签整理插件。本版本补齐单条书签跨分类移动，以及浏览器收藏夹移动到 SmartFav 的实时反向同步。

## 本次更新

- 分类内部每条书签新增“移动”菜单，可直接选择另一个分类。
- 开启“同步浏览器收藏夹”时，SmartFav 的跨分类移动会同步移动浏览器 `SmartFav / 分类` 中的受管书签。
- 在浏览器 `SmartFav / 分类` 间移动单条书签时，SmartFav 会实时更新本地分类与顺序。
- 插件自身的整理、排序和分类移动会被标记为内部操作，不会再次触发反向同步。
- 关键词输入支持空格、逗号、分号和换行分隔。
- 带空格词组可以使用英文双引号保留，例如 `"machine learning"`。
- 跨分类控件已验证 320px、360px 和暗色模式，不产生横向溢出。

## 下载与安装

下载 `SmartFav-Edge-1.13.0.zip`，解压后：

1. 打开 `edge://extensions/` 或 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后包含 `manifest.json` 的目录。

此 ZIP 同时适用于 Edge 和 Chrome 的开发者模式安装，也可用于扩展商店提交。它不是可双击安装的桌面应用安装包。
