# SmartFav 1.15.1

SmartFav 1.15.1 是 1.15.0 多级收藏夹版本的界面与稳定性补丁。

## 更新内容

- 收藏页和分类管理页新增即时搜索与清空操作。
- 设置页按外观、AI、浏览器书签同步、备份与恢复分组，可折叠并显示状态摘要。
- 首页、视图切换、列表、提示条、空状态和排序落位增加轻量动效。
- 尊重系统“减少动态效果”设置，避免持续动画影响可访问性。
- 分类文件夹拖动时根据指针最近边绘制上、下、左、右蓝色落位线：上/左代表插入到目标前，下/右代表插入到目标后。
- 移除拖拽目标上的可见数字标记，同时保留读屏器可用的预计位置提示。
- 删除本地视觉回归使用的默认高亮入口，正式包打开收藏页时不会预选中任何文件夹。
- 拖拽和 `Alt + 方向键` 排序共享一致的落位、焦点恢复与语音提示。
- 统一刷新页面资源版本，避免开发者重载后继续命中旧脚本或旧样式缓存。
- 收藏移动、文件夹跨层移动和删除迁移统一改用独立目录选择页，支持路径搜索、面包屑、多级进入和选择后自动返回，不再使用会覆盖后续内容的下拉层。
- 抽取文件夹导航纯函数，统一收藏页、分类管理和目录选择器的层级解析及面包屑行为，并加入直接单元测试。

## 核心能力基线

- 继承 1.15.0 的任意层级收藏夹树、面包屑导航、跨层移动和旧数据幂等迁移。
- 浏览器 `SmartFav` 子树的新建、移动、重命名、排序和删除可递归双向同步。
- 本地关键词分类始终可用；AI 仅提供可勾选的移动、新建子文件夹和关键词补充建议，未确认不会写入数据。

## 验证

- JavaScript 语法检查、扩展自动化回归、`git diff --check` 均通过。
- ZIP 包与 28 个扩展源文件一致，`unzip -t` 完整性检查通过。

## 安装

下载 `SmartFav-Edge-1.15.1.zip`，解压后在 `edge://extensions/` 或 `chrome://extensions/` 中开启开发者模式并加载解压目录。提交扩展商店时可直接上传 ZIP。
