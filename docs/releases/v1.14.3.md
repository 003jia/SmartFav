# SmartFav 1.14.3

SmartFav 1.14.3 是稳定性与发布一致性版本，重点解决多个异步入口同时修改收藏、回收站、设置和排序时可能互相覆盖的问题。

## 更新内容

- 收藏保存、浏览器星标自动采集、浏览器删除与移动回流、回收站、重新分类和浏览器整理统一进入后台状态事务队列。
- 设置改为后台补丁合并，不再由 popup 使用旧快照直接覆盖整份 settings。
- 分类内书签排序由后台基于最新 `favoriteOrder` 合并。
- 浏览器活动通知按活动 ID 消费，旧 popup 不会清除新活动。
- `storage.local.get` 与 `storage.local.set` 都检查 `chrome.runtime.lastError`。
- 首次安装初始化失败时记录明确错误，不再静默忽略。
- Manifest、CSS、脚本查询串和发布文档统一为 1.14.3。
- 发布包校验会比较 ZIP 与当前源码的文件列表和每个文件内容。

## 新增验证

- popup 保存与浏览器星标自动采集并发
- popup 保存与 SmartFav 删除并发
- popup 保存与浏览器删除回流并发
- 两个设置补丁并发合并
- 不同分类排序并发合并
- 旧活动 ID 不得清除新活动
- storage 读取失败时保持原数据
- 发布 ZIP 与源码逐文件一致

## 安装

下载 `SmartFav-Edge-1.14.3.zip`，解压后：

1. 打开 `edge://extensions/` 或 `chrome://extensions/`。
2. 开启开发者模式。
3. 点击“加载解压缩的扩展”。
4. 选择包含 `manifest.json` 的解压目录。

从旧版本覆盖升级时，浏览器会保留原有 SmartFav 本地收藏、设置、关键词、排序和布局备份。升级后建议先关闭并重新打开一次插件弹窗，再进行浏览器书签同步操作。
