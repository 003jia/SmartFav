# SmartFav 智能收藏夹

SmartFav 是一个本地优先的 Chrome / Edge 收藏扩展。点击工具栏图标后，它会打开浏览器原生矩形插件弹窗，根据网页标题、网址和描述中的关键词给出分类建议；不配置 AI 也能完整收藏。界面支持中英文即时切换，并可选同步到浏览器原生收藏夹。

## 主要能力

- 本地关键词索引分类，默认不上传网页内容
- 分类建议可在收藏前手动调整
- 自定义分类和关键词规则
- 360px 浏览器原生工具栏弹窗，不注入网页、不创建独立窗口
- 工具栏与弹窗标题区使用统一的多尺寸 SmartFav 品牌图标
- 毛玻璃、纯白、灰色、黑色、羊皮纸五种界面风格
- 顶栏明暗切换并自动保存；黑色风格固定使用白色文字
- 可新增、删除分类文件夹，并逐个设置关键词规则
- 中英文界面与 Edge 商店双语言包
- 收藏与删除双向同步、现有收藏整理、星标自动获取三项能力独立控制
- 浏览器收藏支持“覆盖同网址”或“始终新增”
- 重新加载或重新安装后，从旧 `SmartFav / 分类` 自动恢复本地收藏和自定义分类
- AI 作为可选增强，不影响基础收藏流程
- 支持 Ollama 本机模型、OpenRouter 免费路由、MiniMax、DeepSeek 和 OpenAI
- 同一网址重复收藏时自动更新，避免重复条目
- 支持查看全部、收回以及删除单个 SmartFav 收藏网址

## AI 方案

| 方案 | 是否需要 API Key | 说明 |
| --- | --- | --- |
| Ollama | 否 | 模型在本机运行，需要先安装并启动 Ollama |
| OpenRouter 免费路由 | 是 | 使用 `openrouter/free`，免费模型与额度可能变化 |
| MiniMax / DeepSeek / OpenAI | 是 | 使用自己的 API Key 和模型 |

AI 默认关闭。启用后，也只有点击插件弹窗中的“AI 优化”才会发送当前网页的标题、网址和描述。

所有设置都在同一个插件弹窗内完成，不再打开独立的大尺寸设置页面。

## 界面风格与明暗模式

插件设置中可以选择毛玻璃（默认）、纯白、灰色、黑色或羊皮纸。顶栏的 `暗 / 明`（英文界面为 `Dark / Light`）按钮可以快速切换当前风格的明暗模式，风格和明暗选择都会保存在浏览器本地。

黑色风格固定使用暗色模式和白色文字，因此选择黑色后明暗开关会锁定；切换到其他风格即可重新选择明亮或暗色。

## 自定义分类文件夹

在插件弹窗中打开“设置”，找到“分类文件夹”：

1. 输入新文件夹名称并点击“添加”。
2. 在新文件夹下方填写匹配关键词，多个关键词使用中文或英文逗号分隔。
3. 点击“保存设置”，新文件夹会立即显示在 SmartFav 首页。

删除按钮只移除分类配置，不会删除已经保存的 SmartFav 收藏。开启浏览器收藏夹同步后，新分类会在第一次向该分类收藏网页时写入对应的 `SmartFav / 分类` 浏览器目录。

## 中英文切换

插件弹窗右上角提供 `EN / 中` 按钮，点击后立即切换界面语言并保存选择。

- 新安装时会参考浏览器界面语言。
- 使用默认分类时，切换语言会同步切换分类名称和关键词规则。
- 已自定义分类或关键词时，切换界面语言不会覆盖你的规则。
- `_locales/zh_CN` 和 `_locales/en` 会让 Microsoft Edge Add-ons 正确识别简体中文和英文两个商店语言。

## 浏览器收藏夹

浏览器收藏夹设置包含三个独立开关：

- **同步浏览器收藏夹**：从 SmartFav 收藏网页时写入浏览器分类；从 SmartFav 删除时，同步移除浏览器 `SmartFav / 分类` 中的同网址记录。其他浏览器文件夹中的同网址收藏不会被删除。
- **允许整理浏览器收藏夹**：开启后立即读取并整理现有收藏；之后通过星标新增的收藏也会自动移动到匹配分类。关闭时点击“立即整理收藏夹”只导入 SmartFav，不移动浏览器收藏。
- **自动获取浏览器收藏**：点击浏览器星标后自动加入 SmartFav 并分类；允许整理时，同时把该浏览器收藏移动到匹配分类。

写入或整理后的目录结构为：

```text
SmartFav
└── 当前分类
    └── 收藏网页
```

同网址处理方式：

- **覆盖同网址**：在整个浏览器收藏夹内查找相同网址，保留一条、更新标题并移动到当前分类；SmartFav 保存和浏览器星标两条新增路径都遵守该规则。
- **始终新增**：每次都创建新收藏，允许相同网址重复出现。

三个开关默认均关闭，切换后立即保存，无需再点击页面底部的“保存设置”。开启“允许整理浏览器收藏夹”时会立即执行一次现有收藏整理；也可以随时点击“立即整理收藏夹”。整理只移动网址收藏，不删除内容；`SmartFav` 文件夹内的记录不会被重复整理。

## 管理 SmartFav 收藏

展开“我的收藏”后：

- 点击“查看全部”显示完整收藏列表，按钮会变为“收回”。
- 点击每条收藏右侧的“删除”：关闭“同步浏览器收藏夹”时只删除 SmartFav 本地记录；开启后同时删除浏览器 `SmartFav / 分类` 中的同网址记录，不影响其他浏览器文件夹。
- 点击收藏网址时会在当前标签页打开，因此可以直接使用浏览器“返回”回到原页面；进入某个分类后也提供“返回分类”按钮。
- 删除后收藏总数、最近收藏和分类数量会立即刷新。

## 安装

1. 打开 `chrome://extensions/` 或 `edge://extensions/`。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”。
4. 选择当前 `smartFav智能收藏夹` 文件夹。

点击 SmartFav 工具栏图标即可打开浏览器原生插件弹窗，点击弹窗外部即可关闭。普通网页可以读取并收藏；`edge://`、Microsoft Edge Add-ons、Chrome Web Store 等保护页面仍能打开插件并查看已有收藏与设置，但不能读取或收藏当前保护页面。

## 上传 Microsoft Edge Add-ons

1. 使用项目生成的 `dist/SmartFav-Edge-1.6.7.zip`，或自行将 `smartFav智能收藏夹` 文件夹内的文件压缩，确保 `manifest.json` 位于 ZIP 根目录。
2. 在 Microsoft Partner Center 的扩展提交页面上传 ZIP。
3. 上传成功后，在 Store listings 中确认出现“中文（简体）”和“English”。
4. 分别填写两种语言的商店长描述、截图和推广素材。

版本 1.5.0 移除 `action.default_popup`，改为工具栏点击时通过 `activeTab + scripting` 注入隔离的悬浮窗。现有 `popup.html` 作为扩展源 iframe 复用，保留原有收藏、设置、中英文、主题与浏览器收藏夹能力，同时让圆角外部真正显示当前网页。

版本 1.5.1 为 Edge 保护页面增加“我的收藏”备用窗口：当悬浮窗不能注入时，不再只显示红色感叹号，而是仍允许查看已有收藏和进入设置。

版本 1.5.2 修复备用窗口画布高度固定的问题：收藏展开、收起和设置切换时，窗口会根据实际内容高度实时缩放。网页悬浮层的毛玻璃也改由最外层直接模糊当前网页背景。

版本 1.6.0 根据实机反馈回归浏览器原生 `action.default_popup`：删除网页悬浮层与独立备用窗口，外框改为方形，由 Edge / Chrome 负责弹窗显示和关闭。

版本 1.6.1 修复外观联动：选择黑色风格会强制暗色模式；从黑色切换到其他风格时会自动关闭暗色模式并重新启用明暗开关。

版本 1.6.2 完成浏览器收藏夹权限拆分：普通写入、批量整理和星标自动获取互不依赖；补充不写回时仅导入 SmartFav、允许整理时移动原收藏，以及星标事件的完整自动化验证。

版本 1.6.3 增加单条网址删除和“查看全部 / 收回”；统一三项浏览器收藏夹设置的字体与边距；三个收藏夹开关改为即时保存，并修正星标后的浏览器移动由“写入浏览器收藏夹”权限控制。

版本 1.6.4 将“覆盖同网址”扩展到整个浏览器收藏夹，并让 SmartFav 保存与浏览器星标两条路径共同执行覆盖去重；收藏网址改为在当前标签页打开以支持浏览器返回；开启整理后，后续新增星标会自动归类。

版本 1.6.5 修复重新加载或换目录安装后无法识别旧整理结果的问题：弹窗启动时会扫描浏览器中已有的 `SmartFav / 分类`，恢复缺失的本地收藏，保留原分类，并自动补回旧自定义分类；恢复过程不会移动或删除浏览器收藏，也不会重复导入。

版本 1.6.6 将“写入浏览器收藏夹”升级为双向同步：开启后，从 SmartFav 删除收藏会同步移除浏览器 `SmartFav / 分类` 中的全部同网址记录；其他浏览器文件夹中的同网址收藏会保留。浏览器删除失败时，本地记录不会先行删除，避免状态失配。

版本 1.6.7 更新 SmartFav 品牌图标，并在工具栏和弹窗标题区统一使用；同时细化下拉框、按钮、收藏列表、分类项和滚动条的悬停与交互样式。

## 本地分类规则

设置页会为每个分类文件夹提供独立的关键词输入框，例如：

```text
编程：github, 代码, javascript, python
视频：bilibili, youtube, 视频, 直播
```

分类时，标题权重最高，网址次之，页面描述用于补充判断；没有命中时会进入“其他”或最后一个分类。

## 权限说明

- `activeTab`、`scripting`：仅在用户打开插件弹窗后读取当前页面标题和描述用于分类。
- `storage`：在浏览器本地保存设置和 SmartFav 收藏。
- `bookmarks`：仅用于用户主动执行整理、开启星标自动获取或允许同步时读取和维护浏览器收藏；整理只移动网址收藏，删除同步只作用于 `SmartFav / 分类` 受管目录。
- 指定的 AI 服务域名：只在用户主动开启并点击“AI 优化”或“测试连接”时访问。
