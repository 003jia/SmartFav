# SmartFav 智能收藏夹

SmartFav 是一个本地优先的 Chrome / Edge 收藏扩展。点击工具栏图标后，它会打开浏览器原生矩形插件弹窗，根据网页标题、网站标签、网址和描述给出分类建议；不配置 AI 也能完整收藏。界面支持中英文即时切换，并可选同步到浏览器原生收藏夹。

## 主要能力

- 本地关键词权重或关键词向量匹配，默认不上传网页内容
- 分类建议可在收藏前手动调整
- 自定义分类和关键词规则
- 浏览器原生工具栏弹窗，宽度可在 320–520px、高度可在 420–600px 间调整
- 主页、我的收藏、分类文件夹和设置使用独立紧凑界面
- 我的收藏和分类文件夹内容区顶部均提供返回主页按钮
- 保存分类规则后自动重新分类全部已有 SmartFav 收藏
- 工具栏与弹窗标题区使用统一的多尺寸 SmartFav 品牌图标
- 毛玻璃、纯白、灰色、黑色、羊皮纸五种界面风格，并支持本地自定义背景图
- 顶栏明暗切换并自动保存；黑色风格固定使用白色文字
- 可新增、删除分类文件夹，并逐个设置关键词规则
- 中英文界面与 Edge 商店双语言包
- 收藏与删除实时双向同步、现有收藏整理、星标自动获取三项能力独立控制
- 分类内书签可通过“移动”菜单跨分类转移；开启同步后会同时移动浏览器中的 SmartFav 受管书签
- 在浏览器 `SmartFav / 分类` 间移动书签时，SmartFav 会实时更新对应分类和本地顺序
- 整理或自动移动星标前强制创建整理前布局备份，可预览、还原原文件夹与顺序、导入或导出 JSON
- 星标完成本地分类后，用系统通知显示目标分类文件夹
- 浏览器收藏支持“覆盖同网址”或“始终新增”
- 重新加载或重新安装后，从旧 `SmartFav / 分类` 自动恢复本地收藏和自定义分类
- AI 作为可选增强，可自动分类、按现有规则证据判断，并在允许时创建新分类文件夹
- 可用当前 AI 分析各分类文件夹中的收藏标题、域名和网址路径，把候选关键词填入匹配字段后再由用户确认保存
- 标签比例权重和分类关键词向量匹配两种分类策略
- 支持 Ollama 本机模型、OpenRouter 免费路由、MiniMax、DeepSeek、OpenAI，以及自定义 OpenAI / Anthropic 兼容 API
- 同一网址重复收藏时自动更新，避免重复条目
- 支持查看全部、收回以及删除单个 SmartFav 收藏网址
- 删除内容进入“最近删除”，7 天内可恢复或立即永久删除

## AI 方案

| 方案 | 是否需要 API Key | 说明 |
| --- | --- | --- |
| Ollama | 否 | 模型在本机运行，需要先安装并启动 Ollama |
| OpenRouter 免费路由 | 是 | 使用 `openrouter/free`，免费模型与额度可能变化 |
| MiniMax / DeepSeek / OpenAI | 是 | 使用自己的 API Key 和模型 |
| OpenAI 兼容 API | 是 | 填写完整 Chat Completions 地址、模型和 API Key |
| Anthropic 兼容 API | 是 | 填写完整 Messages 地址、模型和 API Key |

AI 默认关闭。启用后可选择打开插件时自动优化，也可以关闭自动模式，仅在点击“AI 优化”时发送当前网页标题、网站标签、网址和描述。开启“允许 AI 创建分类文件夹”后，模型仅在现有分类都不合适时提出新文件夹及其关键词；保存收藏时会按当前浏览器同步权限写入对应分类。

“分类文件夹”中的“AI 分析并填入”会分析每个非空文件夹内最多 12 条代表性收藏。请求包含文件夹名、已有普通关键词、收藏标题、域名和不含查询参数的网址路径，不发送完整网址查询参数。文件夹较多时按 5 个一批处理；只有全部请求成功后才把建议合并到输入框。AI 不会覆盖原关键词，也不会生成 `domain:` 规则；建议只有在用户点击“保存并重新分类”后才会持久化。

选择兼容 API 时，API 地址必须是完整请求地址，例如 `https://gateway.example.com/v1/chat/completions` 或 `https://gateway.example.com/v1/messages`。远程地址只允许 HTTPS；HTTP 仅允许 `localhost` 或 `127.0.0.1`。更改接口或测试连接时，浏览器只会请求该 API 主机的访问权限，不会授予所有网站的常驻访问权限。

所有设置都在同一个插件弹窗内完成，选择、切换或编辑后自动保存，不再打开独立的大尺寸设置页面，也不再显示页面底部的“保存设置”按钮。

## 界面风格与明暗模式

插件设置中可以选择毛玻璃（默认）、纯白、灰色、黑色或羊皮纸。顶栏的 `暗 / 明`（英文界面为 `Dark / Light`）按钮可以快速切换当前风格的明暗模式，风格和明暗选择都会保存在浏览器本地。

黑色风格固定使用暗色模式和白色文字，因此选择黑色后明暗开关会锁定；切换到其他风格即可重新选择明亮或暗色。

同一设置区还可以调整弹窗宽高，并上传 JPG、PNG、WebP 或 GIF 背景图（最大 3MB）。图片转换后只保存在浏览器本地，选择后立即预览并自动保存，也可以随时清除。

## 自定义分类文件夹

在插件主页点击“分类文件夹”进入独立管理界面：

1. 输入新文件夹名称并点击“添加”。
2. 在新文件夹下方填写匹配关键词。空格、英文或中文逗号、中文或英文分号和换行都可以作为分隔符；带空格的完整词组请使用英文双引号，例如 `"machine learning"`。输入完成后会自动统一为英文逗号格式，并保留带引号词组。
3. 如已启用 AI，可点击“AI 分析并填入”，检查各文件夹中标记为 `AI +数量` 的新增建议。
4. 点击“保存并重新分类”。

保存后，SmartFav 会使用每条收藏已经保存的标题、网址和页面描述重新运行本地分类器，更新分类、命中关键词和分类说明；旧收藏没有页面描述时仍会使用标题和网址。删除分类文件夹不会删除收藏，相关收藏会在保存时进入新的匹配分类或兜底分类。

开启浏览器收藏夹同步后，已经位于浏览器 `SmartFav / 分类` 目录中的收藏也会移动到重新匹配的分类；其他浏览器文件夹中的同网址收藏不会被修改。新分类会在第一次收藏或同步移动时创建对应目录。

## 中英文切换

插件弹窗右上角提供 `EN / 中` 按钮，点击后立即切换界面语言并保存选择。

- 新安装时会参考浏览器界面语言。
- 使用默认分类时，切换语言会同步切换分类名称和关键词规则。
- 已自定义分类或关键词时，切换界面语言不会覆盖你的规则。
- `_locales/zh_CN` 和 `_locales/en` 会让 Microsoft Edge Add-ons 正确识别简体中文和英文两个商店语言。

## 浏览器收藏夹

浏览器收藏夹设置包含三个独立开关：

- **同步浏览器收藏夹**：从 SmartFav 收藏网页时写入浏览器分类；从 SmartFav 删除时，同步移除浏览器 `SmartFav / 分类` 中的同网址记录；手动拖动分类或分类内书签时，同步写回浏览器中的顺序；使用“移动”菜单跨分类时，同步移动浏览器中的受管副本；在浏览器 `SmartFav / 分类` 间移动书签时，SmartFav 也会实时更新分类；在浏览器删除最后一条同网址书签时，将 SmartFav 记录实时移入“最近删除”。如果浏览器中仍有其他同网址副本，SmartFav 不会误删。
- **允许整理浏览器收藏夹**：开启后立即读取并整理现有收藏；之后通过星标新增的收藏也会自动移动到匹配分类。关闭时点击“立即整理收藏夹”只导入 SmartFav，不移动浏览器收藏。
- **自动获取浏览器收藏**：点击浏览器星标后自动加入 SmartFav 并分类，分类完成后用系统通知提示目标文件夹；允许整理时，同时把该浏览器收藏移动到匹配分类。开启此项后，浏览器删除最后一条同网址书签也会同步移入 SmartFav“最近删除”。

写入或整理后的目录结构为：

```text
SmartFav
└── 当前分类
    └── 收藏网页
```

同网址处理方式：

- **覆盖同网址**：在整个浏览器收藏夹内查找相同网址，保留一条、更新标题并移动到当前分类；SmartFav 保存和浏览器星标两条新增路径都遵守该规则。
- **始终新增**：每次都创建新收藏，允许相同网址重复出现。

三个开关默认均关闭，切换后立即保存。开启“允许整理浏览器收藏夹”时会立即执行一次现有收藏整理；也可以随时点击“立即整理收藏夹”。整理只移动网址收藏，不删除内容；`SmartFav` 文件夹内的记录不会被重复整理。

### 整理前布局备份

设置页的“整理前布局备份”用于撤销 SmartFav 对浏览器收藏夹结构的整理：

- 批量整理或自动移动新星标前，SmartFav 必须先把仍在 `SmartFav` 外的书签 ID、原文件夹路径和顺序保存到扩展本地；备份保存失败会直接中止移动。
- 已经位于 `SmartFav / 分类` 的书签仍会被读取并计数，但浏览器 API 不提供其整理前路径。界面会显示“无历史位置”，不会把 `0 条可还原记录`误写成“可还原”。
- 在一次还原完成前，同一份活动备份会持续补充后续新增的外部书签；最多保留 3 份。
- “查看可还原项”只统计即将移动、已在原位置、缺失书签和需要重建的文件夹，不修改收藏夹。
- “还原整理前位置”仅移动仍存在且 ID 匹配的书签，按需重建缺失的原文件夹，并清理本次整理新建且已经为空的 `SmartFav` 文件夹；之后新增的书签不会被删除，用户已删除的书签不会重新创建。
- 还原可以重复执行，已经还原的书签不会复制。当前备份为 0 条时，查看、还原和导出按钮会禁用。
- “导出布局备份”生成 JSON 文件，“导入布局备份”可在重新安装后重新载入。浏览器不允许扩展在卸载完成后继续运行，无法自动执行还原；卸载前必须手动还原或导出。

## 管理 SmartFav 收藏

在插件主页点击“我的收藏”进入独立收藏界面：

- 使用内容区顶部的“返回主页”回到插件主页；分类文件夹界面也提供相同入口。
- 点击“查看全部”显示完整收藏列表，按钮会变为“收回”。
- 点击每条收藏右侧的“删除”：收藏先进入“最近删除”；关闭“同步浏览器收藏夹”时只移除 SmartFav 本地记录，开启后同时删除浏览器 `SmartFav / 分类` 中的同网址记录，不影响其他浏览器文件夹。
- “最近删除”默认保留 7 天，可以恢复收藏，也可以点击“彻底删除”立即永久删除；后台每小时清理一次到期记录。
- 点击收藏网址时会在当前标签页打开，因此可以直接使用浏览器“返回”回到原页面；进入某个分类后也提供“返回分类”按钮。
- 分类内收藏使用紧凑卡片显示：长标题最多显示两行，第二行显示网站域名，删除按钮位于独立操作区。
- 分类内每条收藏提供“移动”菜单，可直接选择另一个分类；移动后保留原分类页面并立即刷新两侧数量。
- 删除后会保持在当前分类并刷新空状态、收藏总数、最近收藏和分类数量。

## 安装

1. 打开 `chrome://extensions/` 或 `edge://extensions/`。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”。
4. 选择当前 `smartFav智能收藏夹` 文件夹。

点击 SmartFav 工具栏图标即可打开浏览器原生插件弹窗，点击弹窗外部即可关闭。普通网页可以读取并收藏；`edge://`、Microsoft Edge Add-ons、Chrome Web Store 等保护页面仍能打开插件并查看已有收藏与设置，但不能读取或收藏当前保护页面。

## 上传 Microsoft Edge Add-ons

1. 使用项目生成的 `dist/SmartFav-Edge-1.15.1.zip`，或自行将 `smartFav智能收藏夹` 文件夹内的文件压缩，确保 `manifest.json` 位于 ZIP 根目录。
2. 在 Microsoft Partner Center 的扩展提交页面上传 ZIP。
3. 上传成功后，在 Store listings 中确认出现“中文（简体）”和“English”。
4. 分别填写两种语言的商店长描述，并使用虚拟测试数据在本地生成对应语言的 `1280 × 800` 截图；确认截图不含真实书签、邮箱、头像、账号名称、本机路径或内部网址后，直接上传到商店后台。公开仓库不保存商店截图素材。
5. 隐私政策填写 `https://github.com/003jia/SmartFav/blob/main/PRIVACY.md`。
6. 发布方联系邮箱必须在 Partner Center 的开发人员设置中单独保存并完成验证；这项账号信息不包含在扩展包中。

完整的权限用途、单一用途说明、隐私披露和邮箱验证步骤见仓库的 [`docs/edge-store-submission.md`](../docs/edge-store-submission.md)。

## 版本记录

版本 1.5.0 移除 `action.default_popup`，改为工具栏点击时通过 `activeTab + scripting` 注入隔离的悬浮窗。现有 `popup.html` 作为扩展源 iframe 复用，保留原有收藏、设置、中英文、主题与浏览器收藏夹能力，同时让圆角外部真正显示当前网页。

版本 1.5.1 为 Edge 保护页面增加“我的收藏”备用窗口：当悬浮窗不能注入时，不再只显示红色感叹号，而是仍允许查看已有收藏和进入设置。

版本 1.5.2 修复备用窗口画布高度固定的问题：收藏展开、收起和设置切换时，窗口会根据实际内容高度实时缩放。网页悬浮层的毛玻璃也改由最外层直接模糊当前网页背景。

版本 1.6.0 根据实机反馈回归浏览器原生 `action.default_popup`：删除网页悬浮层与独立备用窗口，外框改为方形，由 Edge / Chrome 负责弹窗显示和关闭。

版本 1.6.1 修复外观联动：选择黑色风格会强制暗色模式；从黑色切换到其他风格时会自动关闭暗色模式并重新启用明暗开关。

版本 1.6.2 完成浏览器收藏夹权限拆分：普通写入、批量整理和星标自动获取互不依赖；补充不写回时仅导入 SmartFav、允许整理时移动原收藏，以及星标事件的完整自动化验证。

版本 1.6.3 增加单条网址删除和“查看全部 / 收回”；统一三项浏览器收藏夹设置的字体与边距；三个收藏夹开关改为即时保存，并修正星标后的浏览器移动由“写入浏览器收藏夹”权限控制。

版本 1.6.4 将“覆盖同网址”扩展到整个浏览器收藏夹，并让 SmartFav 保存与浏览器星标两条路径共同执行覆盖去重；收藏网址改为在当前标签页打开以支持浏览器返回；开启整理后，后续新增星标会自动归类。

版本 1.6.5 修复重新加载或换目录安装后无法识别旧整理结果的问题：弹窗启动时会扫描浏览器中已有的 `SmartFav / 分类`，恢复缺失的本地收藏，保留原分类，并自动补回旧自定义分类；恢复过程不会移动或删除浏览器收藏，也不会重复导入。

版本 1.6.6 将“写入浏览器收藏夹”升级为双向同步：开启后，从 SmartFav 删除收藏会同步移除浏览器 `SmartFav / 分类` 中的全部同网址记录；其他浏览器文件夹中的同网址收藏会保留。浏览器删除失败时，本地记录不会先行删除，避免状态失配。

版本 1.6.7 更新 SmartFav 品牌图标，并在工具栏和弹窗标题区统一使用；同时细化下拉框、按钮、收藏列表、分类项和滚动条的悬停与交互样式。

版本 1.7.0 将“我的收藏”和“分类文件夹”拆为独立紧凑界面，主页只保留当前网页收藏与功能入口；保存分类文件夹或关键词规则后，会重新检查全部已有收藏，并在启用浏览器同步时移动 SmartFav 受管浏览器收藏。

版本 1.8.0 为“我的收藏”和“分类文件夹”补充内容区返回按钮；增加可调弹窗宽高与自定义背景图；AI 增强支持自动分类、创建新分类文件夹、标签比例权重和分类关键词向量匹配；删除操作改为进入保留 7 天的“最近删除”，支持恢复、立即永久删除和后台到期清理。

## 本地分类规则

设置页会为每个分类文件夹提供独立的关键词输入框，例如：

```text
编程：github, 代码, javascript, python
视频：bilibili, youtube, 视频, 直播
学习：教程, 文档, domain:docs.example.com
```

标签比例权重模式默认使用：标题 5、网站标签 6、网址 3、页面描述 1，标签权重可在设置中调整。关键词向量模式会把网页字段与每个分类文件夹的名称和关键词规则构造成本地向量，再用余弦相似度选择最接近的分类；没有明显匹配时进入“其他”或最后一个分类。

`domain:` 是 SmartFav 的透明域名优先规则。比如 `domain:docs.example.com` 会优先匹配该域名及其子域名。手动移动书签后只有点击“记住”才会创建该规则；当前网页手动改分类时可通过默认勾选项同时保存规则。规则仍然是普通可编辑文本，不会隐藏在模型或远端服务中。

## 权限说明

- `activeTab`、`scripting`：仅在用户打开插件弹窗后读取当前页面标题和描述用于分类。
- `storage`：在浏览器本地保存设置、SmartFav 收藏、最近删除和整理前布局备份；用户可主动把布局备份导出为 JSON。
- `bookmarks`：仅用于用户主动执行整理、开启星标自动获取或允许同步时读取和维护浏览器收藏；整理前记录并按用户操作恢复原文件夹与顺序；监听新建、移动和删除事件以执行已开启的实时同步，删除最后一个同网址浏览器副本时才移入 SmartFav“最近删除”。
- `alarms`：每小时检查“最近删除”并清理超过 7 天的记录。
- `notifications`：仅在浏览器星标完成分类后，在本机显示目标分类提示；不会发送或上传通知内容。
- 指定的 AI 服务域名：只在用户主动开启 AI 后，由自动分类、“AI 优化”、“AI 分析并填入”或“测试连接”访问。
- 可选 API 主机权限：选择 OpenAI / Anthropic 兼容 API 后，仅在更改接口或测试时请求用户填写的 HTTPS 主机；本机 HTTP 仅限 `localhost` 和 `127.0.0.1`。
